WEBSITE PERMINTAAN MAAF UNTUK ZALFFA

Cara membuka:
1. Ekstrak file ZIP.
2. Buka index.html di Chrome untuk melihat preview lokal.
3. Tombol musik menjalankan melodi instrumental sederhana yang dibuat browser. Ketuk tombolnya terlebih dahulu karena browser biasanya memblokir autoplay.

Cara online-kan dari HP:
- Upload file index.html, styles.css, dan script.js ke repository GitHub.
- Hubungkan repository ke Vercel atau gunakan fitur upload yang tersedia di layanan hosting statis.
- Pastikan ketiga file berada di folder yang sama.

Catatan:
- Musiknya instrumental sederhana, bukan lagu komersial.
- Nama dan teks permintaan maaf dapat diubah langsung di index.html.
